# Public Assets Redesign

A pagina publica de Ativos deixa de ser catalogo tecnico e passa a ser mecanismo de descoberta do proximo fluxo.

Hierarquia: descoberta por intencao, proximos eventos, recorrencia, data-com proxima, maiores retornos de evento, ativos por mes, papel no fluxo, comparacao e catalogo completo secundario.

Ausencia de dado nao deve ser exibida como zero.
