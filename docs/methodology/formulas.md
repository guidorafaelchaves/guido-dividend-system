# Formulas

Retorno do evento: `valor por unidade / preco de referencia * 100`.

DY equivalente: `retorno do evento * frequencia teorica`.

Yield on Cost: `valor por unidade / preco medio do usuario * 100`.

Valor previsto: `quantidade elegivel * valor por unidade`.

Confianca do periodo: `(confirmados + provisionados) / total previsto`.
